# APIApp_AxelMtz
This activity was made to apply APIs and Web development. Activity from 'Professional Web Development' class by the Teacher Miguel Gutierrez Baca from UTCH BIS.


Instructions

As we saw in Unit 1, you must develop a website including a sidebar, a navbar, a main container, and a footer. Additionally, the website needs to be dynamic, incorporating at least one search method and general API consumption . It must feature real content and practical use cases (for example, a Pokedex using the PokeAPI, though you cannot use that specific example since it is already taken XD).

You must consume different APIS, you cannot reuse something that your classmates aready used 

You have to publish you website on vercel 


Please note that this practice covers two assignments.
